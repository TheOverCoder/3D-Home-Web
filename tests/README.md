# Tests

Two kinds: **unit tests** (Vitest, in Node: the rules, the saves and the models, in seconds) and the **end-to-end
suite** (Playwright: the game itself in a browser, about 25 minutes). `npm run check` runs the unit tests after the type
check and the linter; CI runs it beside the e2e shards.

## Unit tests

the way the page starts from a save); a test that guards against a loop that never ends runs the code through

## End-to-end tests

Playwright (Chromium, software WebGL) drives the production build through the `?debug` hooks
(`window.__home`: the zustand store, `playerState`, `teleport`, `look`, `camera`, `scene`, `gl`, `physics`, `view` (the drawing pass's switches and counters), `walk` (walking to a compass mark: start and stop one, how it ended, what it cost, a way found at once), `market` (the supermarket's interior casters, for `16`), and `fx`: the
effects' counts — bursts started and alive, coin flights, XP crystals — a clock to slow them for a screenshot, and `play` to start one).
Tests assert behaviour via the store and the player state, never exact copy, and pixels only twice: the bad-pixel test in `06` measures the share of pure-black pixels, because that bug was purely visual, and `24` the night's mean brightness (never black).

### Run

```bash
npm ci
npx playwright install chromium          # once (CI does this with --with-deps)
npm run test:e2e                         # builds, serves on :4185, runs everything sequentially
```

Offline / sandbox with a preinstalled browser:

```bash
PW_CHROMIUM_PATH=/opt/pw-browsers/chromium npm run test:e2e
```

If something is already serving the build on port 4185 it is reused (outside CI). Software rendering is slow
(1-5 fps), so timeouts are generous; the whole run takes roughly 45 minutes (`05` alone: its three walks 10-20, ten times
the farm as long again). One worker, one browser: don't parallelise.

Twelve tests start a page of their own (fresh boots on High and Medium, the lost context, the phone, the loader and its
second visit, the graphics lost while starting, ten times the farm in `05`, the measuring tool, the phone walking to a
compass mark in `19`, the farm opened again an hour later in `20`, the phone with a level claimed and opened again in
`22`, the farm closed an hour with the shop stocked in `23`) and take most of that time; they are tagged `@boot`.
While iterating, `npm run test:e2e:quick` runs everything else (about 20 minutes).

Nine tests are tagged `@full` as well: stable ones that boot a page of their own (High and Medium in `06`, the lost
context, the loader and the graphics lost while starting in `11`), the budget walk at ten times the farm in `05`, the
counting check `26`, and in `16` the phone held upright and the sun's map kept. `05` runs on the drawing-free WebGL
context (`nullgl.js`, `countingTest` in `helpers.ts`): the counts are three.js's own, on the CPU, and `26` checks them
against a real context view by view; the frames come at full speed, so its three walks take about a minute. A push runs the core
suite on GitHub without them (`ci.yml`, `--grep-invert @full`, six shards; `npm run test:e2e:core` locally); they run
every night and by hand (`full.yml`, Run workflow), and a red night is the next thing to fix. Locally, run only the
file of the area a change touches.

One browser page is shared by the whole run (`helpers.ts`, the worker-scoped `game` fixture) because booting
the scene takes a minute or more. `game.ready()` resets the world before each test (spawn, nothing open or carried, every pickup where it started,
lamps on, door shut, the farm's clock at noon and stopped: the light never changes between two frames compared), so tests are independent in effect. The files run in order: `01-boot` boots the page.

### The budget's debts

Views over the budget today, with the drawing pass on and the hedge and the woods in pieces (`DEBTS` in `05`). Each
may draw no more than its ceiling — the most it measured, and 5 % more, for what wanders in and out of a view (the
yard back at the house sideways measured 249k to 263k over three runs, as the hens cross the edge of the view) — so a
debt only goes down; once it measures 5 % under the budget it is paid, and must leave the list (and this table). They
are paid by how things are drawn, never by what the game holds (CLAUDE.md): **occluders** — the farm's buildings hiding
what is behind them, as the house's walls do (third person over the yard: a fifth to a third of it is behind
something); **merged** — the merged pieces left out one by one where they cannot be seen (a merged mesh is drawn
whole); **furniture** — fewer furniture draws, the pieces of one kind in a room drawn together (and so into the sun's
map). Levels of detail (a model far off drawn with fewer triangles) were measured and pay nothing: far people change
pixels below a pixel's size (in faces, hair and shoes), and at the scale where no pixel changes they save 9 %.
