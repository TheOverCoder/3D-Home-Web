# Tests

Two kinds: **unit tests** (Vitest, in Node: the rules, the saves and the models, in seconds) and the **end-to-end
suite** (Playwright: the game itself in a browser, about 25 minutes). `npm run check` runs the unit tests after the type
check and the linter; CI runs it beside the e2e shards.

## Unit tests

## End-to-end tests

Playwright (Chromium, software WebGL) drives the production build through the `?debug` hooks
(`window.__home`: the zustand store, `playerState`, `teleport`, `look`, `camera`, `scene`, `gl`, `physics`, `view` (the drawing pass's switches and counters), and `fx`: the
effects' counts — bursts started and alive, coin flights — a clock to slow them for a screenshot, and `play` to start one).
Tests assert behaviour via the store and the player state, never exact copy, and pixels only once: the bad-pixel test in `06` measures the share of pure-black pixels, because that bug was purely visual.

### Run

```bash
npm ci
npx playwright install chromium          # once (CI does this with --with-deps)
npm run test:e2e                         # builds, serves on :4185, runs everything sequentially
```

Offline / sandbox with a preinstalled browser:

```bash
PW_CHROMIUM_PATH=/opt/pw-browsers/chromium npm run test:e2e
```

If something is already serving the build on port 4185 it is reused (outside CI). Software rendering is slow
(1-5 fps), so timeouts are generous; the whole run takes roughly 45 minutes (`05` alone: its three walks 10-20, ten times
the farm as long again). One worker, one browser: don't parallelise.

Seven tests start a page of their own (fresh boots on High and Medium, the lost context, the phone, the loader and its
second visit, the graphics lost while starting, ten times the farm in `05`, the measuring tool) and take most of
that time; they are tagged `@boot`.
While iterating, `npm run test:e2e:quick` runs everything else (about 20 minutes); the whole suite still runs before a
push, and CI runs it all in four shards.

One browser page is shared by the whole run (`helpers.ts`, the worker-scoped `game` fixture) because booting
the scene takes a minute or more. `game.ready()` resets the world before each test (spawn, nothing open or carried, every pickup where it started,
lamps on, door shut), so tests are independent in effect. The files run in order: `01-boot` boots the page.

### The budget's debts

Views over the budget today, with the drawing pass on and the hedge and the woods in pieces (`DEBTS` in `05`). Each
may draw no more than its ceiling — the most it measured, and 5 % more, for what wanders in and out of a view (the
yard back at the house sideways measured 249k to 263k over three runs, as the hens cross the edge of the view) — so a
debt only goes down; once it measures 5 % under the budget it is paid, and must leave the list (and this table). They
are paid by how things are drawn, never by what the game holds (CLAUDE.md): **LOD** — a model far off drawn with the
