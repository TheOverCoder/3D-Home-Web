## צ'קליסט: מה שבטוח עוזר לפיתוח (לזכור)

      את קוד היציאה שלו, לא פלט מסונן: ב-23.11 קובץ לא מעוצב עבר כך ל-GitHub.
- [ ] בדיקת הדפדפן של האזור שהשתנה, ורק היא (`--grep-invert @full`). את השאר בודק GitHub. איזו בדיקה: הכלי
      `node scripts/affected-specs.mjs` אומר לפי השינוי (`--run` גם מריץ). הוא קיים מהריצה של v1, ולא השתמשנו בו.

- [ ] בדיקה לא נשענת על הגרלה אחת: קוביות החווה (`setRandom`), זרע קבוע, או מה שהיא צריכה נקבע בה. שתי בדיקות
      "לא יציבות" השבוע היו בדיוק זה (ההזמנה עם פריט אחד, והצליל של החלב).
- [ ] שינוי גדול: `/code-review` לפני הדחיפה (קורא שני, בלי שירות חיצוני ובלי PR).
- [ ] שימוש ב-API של three.js, R3F או drei שלא בטוח: לקרוא את התיעוד העדכני (Context7, מחובר בסשן), לא מהזיכרון.

## בסוף: מה שצריך את המחשב שלך, ושיפורים

**הדרך הפשוטה: Claude Code שרץ על המחשב עצמו (Windows, לא WSL).** ב-WSL כרטיס המסך עובד רק עם תוספות, ולא תמיד.
1. Node 22.12 ומעלה, ו-Git for Windows.
2. ב-PowerShell:
   ```
   git clone https://github.com/TheOverCoder/3D-Home-Web.git C:\dev\3D-Home-Web
   cd C:\dev\3D-Home-Web; npm ci; npx playwright install chromium; npm run check
   $env:PW_GPU='1'; npx playwright test --trace off --grep-invert '@full' tests/e2e/22-xp.spec.ts
   ```
   (`'@full'` במרכאות ב-PowerShell.) אם הציור נופל לתוכנה, הבדיקה עוצרת ואומרת מה קיבלה.
3. Claude Code על המחשב: `irm https://claude.ai/install.ps1 | iex`, ואז `claude` בתיקייה הזו.
4. מדידה ראשונה: 22 לוקחת כאן 6 דקות. ההערכה: פי 3–4 מהר יותר. המספר האמיתי ייכנס לכאן.

**הדרך השנייה: הסשן בענן משתמש בתיקייה במחשב** (Remote Control). השלוש שהופיעו (WEB SPACE, core-terminal, Claude
Motion Grafix) "לא זמינות", בלי סיבה. הסיבות הנפוצות: אפליקציית Claude ישנה, או תיקייה מוסתרת תחת תיקיית הבית.
לעדכן את האפליקציה, להוסיף את `C:\dev\3D-Home-Web` ב-Settings → Claude Code → Remote Control, להשאיר את
האפליקציה פתוחה, ולכתוב לי. גם אז זה לא בטוח שיעבוד, ולכן הדרך הראשונה עדיפה.

**מה עוד רק על המחשב (או בטלפון שלך)**
- `?fps` בטלפון מעל החווה: התשובה לספק הראשון למעלה.
- Spector.js או Three.js DevTools בדפדפן: כשמבט עובר את 700 הציורים, רואים בדיוק מה נוסף.
- 05 ו-16 על כרטיס המסך כשמשנים מודלים או אור: דקות במקום חצי שעה.
- CI ב-GitHub נשאר בציור בתוכנה: אותה תמונה בכל ריצה. כרטיס המסך רק מאיץ את העבודה אצלך.
