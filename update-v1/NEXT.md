**חבילות ומנועים מוכנים:** לא צריך אף חבילה חדשה לאף סעיף. הכול נבנה ממה שכבר בפרויקט (three.js, R3F, drei,
Playwright, vitest). כלי סקירת קוד (CodeRabbit, Greptile, Qodo, Copilot, Claude Code Review) נבדקו ונפסלו: כולם דורשים
Pull Request, עולים כסף לכל סקירה, ואף אחד לא היה תופס את מה שנשבר אצלנו, כי הם קוראים קוד ולא מריצים אותו.
